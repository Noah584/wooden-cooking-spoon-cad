3D solid and surface CAD model of an ergonomic wooden cooking spoon designed in **Onshape**.

## Design Highlights & Features
* **Ergonomic Handle Profile:** Handle cross-section contoured for comfortable grip control and balanced weight distribution during stirring.
* **Smooth Bowl Transition:** Tangent-continuous lofted neck blending the handle into a deep, scooped bowl geometry with filleted edges to prevent scratching cookware.
* **Manufacturing-Ready Geometry:** Designed with smooth, continuous curvature suitable for CNC router toolpaths or traditional woodworking templates.
